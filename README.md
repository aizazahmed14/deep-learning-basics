# deep-learning-basics

## Overview:
This repository contains code examples and explanations for building simple neural networks using TensorFlow and PyTorch. These examples illustrate key concepts of deep learning and neural network design for beginners.

## Contents:
### TensorFlow Neural Network:

Dense layers with ReLU and softmax activation
Model compilation and summary
### PyTorch Neural Network:

Custom SimpleNN class definition
Training components: loss function and optimizer

### Usage Instructions:
1. Clone the repository:
```bash
git clone https://github.com/YourUsername/deep-learning-basics.git
cd deep-learning-basics

``` 
2. Install required libraries:
```bash
pip install tensorflow torch numpy

```
3. Run the examples in deep_learning_basics.ipynb or as standalone scripts.

## Key Learnings:
Understand how neural networks function.
Learn to build models using TensorFlow and PyTorch.
Gain insights into activation functions and optimization techniques.
